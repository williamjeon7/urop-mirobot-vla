# 좌표 맞추기 — Mirobot 홈은 그대로 두고 Panda 를 맞춘다

> **절차** · 확인 2026-10-05 · 기준 `cosmos-policy@18a2acc`, LIBERO 탁상(윗면 0.90m)
> 두 로봇의 좌표를 어떻게 맞출지 — 어디를 짝짓고, 배율은 무엇이 정하고, 세로는 어떻게 맞추나. Panda 쪽은 시뮬에서 잰 값이고,
> Mirobot 쪽 `Zt` 는 로봇 노트북에서 쟀다 (10/5, 6절). `→` 뒤 빈칸은 미리 채우지 않는다.

## 0. 한 줄로

**Mirobot 은 늘 홈에서 시작하고, 시뮬 Panda 의 시작 자세를 거기에 맞춘다** (10/5 오후에 바꿨다).
짝은 "Panda 시작 ↔ Mirobot 홈" 이고, **배율은 세로 정렬 하나로 정해진다** —

```
s = (Mirobot 홈 플랜지 Z − Zt) / (Panda 시작 파지점 − Panda 닿는 점) = (230.72 − Zt) / 264.1mm
```

가로 도달 범위는 배율이 아니라 **장면 설계**가 맞춘다 — 우리 블록은 Mirobot 이 닿는 곳에 놓는다.
실물에서 잴 것은 **`Zt` 하나** (집게가 수직일 때 작업대에 닿는 플랜지 Z) 이고, 수직 자세라 **`L` 은 이 식에서 빠진다.**
**10/5 실측 — `Zt` 55.715mm(집게 연 상태) → 배율 s = 0.663.** 세로 하한은 집게를 닫은 상태의 `Zt` 60.713mm 에 여유 5~10mm 를 얹은
**플랜지 Z 66~71mm** 이고, 이건 코드에서 막아야 한다 (7절).

| **Panda 시작** | 시뮬에서 세운다 | **LIBERO 기본 자세** — 빈 탁상의 시작 파지점 `(−0.2085, 0, 1.1733)`, 노이즈 없음. LIBERO-Spatial 10개 평균(1.1753)과 2mm 차라 학습 분포 안이다 |

| **가로 도달** | **장면 설계** | 블록을 Mirobot 이 닿는 곳에 놓고, 시뮬 장면은 그 자리를 거꾸로 옮겨 만든다 (5절) |

**무엇이 풀리나**

- Mirobot 시작 자세가 거부될 일이 없다 — 홈이다. 시작 전에 한 줄 더 움직일 필요도 없다
- Panda 시작이 고정이라 에피소드마다 흔들리지 않는다
- 배율별 시작 자세를 실물에서 하나씩 시험할 필요가 없다 — 실물에서 잴 것은 `Zt` 하나다

**대가** — Panda 시작을 LIBERO 에서 멀리 옮기면 정책이 받는 proprio 가 학습 분포 밖으로 나간다 (action 번역에서도 proprio 는 Panda 형식이다,
[CHECKLIST.md](CHECKLIST.md) 2-4). 그래서 **Panda 시작 높이는 LIBERO 그대로 두고 배율을 맞춘다.** 반대로 배율을 먼저 정하면
(예: 0.44) Panda 시작을 닿는 점 위 400mm 로 — LIBERO 보다 135mm 높게 — 세워야 한다

## 4. 정렬식과 배율

**세로는 "닿는 점" 끼리** — 로봇 노트북은 Mirobot 집게 끝을 작업대에 대고 `?` 의 Z 를 읽고, 여기서는 같은 일을 시뮬 Panda 로 했다.
닿는 상태끼리 짝지으니 두 집게의 생김새가 저절로 들어간다.

```
Mirobot 플랜지 Z = Zt + s × (Panda 파지점 z − 0.9092m)        (수직 자세)
Panda 시작(1.1733m) ↔ Mirobot 홈(230.72mm)  ⇒  s = (230.72 − Zt) / 264.1mm
```

**수직 자세에서는 `L` 이 빠진다** — Mirobot 에 주는 것도 닿는 점도 플랜지라 `L` 이 상쇄된다. 시작 자세(B 3.2°)로 확인:

| `L` | 시작 플랜지 Z − 닿는 점 플랜지 Z | 시작 플랜지 X |
|---|---|---|
| 50mm | **+116.54mm** | 122.79 |
| 55mm | **+116.53mm** | 123.07 |
| 60mm | **+116.53mm** | 123.35 |

세로 차는 0.01mm 안에서 같다. `L` 은 자세가 기울 때 가로로만 들어온다 (±5mm 가 X ±0.28mm). (이 확인은 배율 0.44 · 짝 X 120 으로 했지만 상쇄는 짝·배율과 무관하다)

**`Zt` 에 따른 배율** — 실측 전에 만든 표다. 실측은 표 아래

| `Zt` (플랜지) | Mirobot 홈이 닿는 점 위 | **배율 s** | Mirobot 100mm 가 Panda 에서 | LIBERO 정책의 최저 높이(닿는 점 위 4.0mm)가 Mirobot 에서 |
|---|---|---|---|---|
| 45mm | 185.7mm | 0.703 | 142mm | 2.8mm |
| 50mm | 180.7mm | 0.684 | 146mm | 2.7mm |
| **55mm** | **175.7mm** | **0.665** | **150mm** | **2.7mm** |
| 60mm | 170.7mm | 0.646 | 155mm | 2.6mm |
| 65mm | 165.7mm | 0.627 | 159mm | 2.5mm |

55mm 는 "Mirobot 파지점이 작업대에서 Z 0" 일 때(`L` 55mm)의 값이다. **배율은 약 0.63~0.70 범위에 들 것이다** — 10/1 의 후보 0.44 나
두 로봇 도달 거리 비 0.37 보다 크다. Mirobot 이 블록까지 100mm 움직이는 동작이 Panda 에서는 140~160mm 라 LIBERO 동작 크기 안이다

**실측 (10/5, 로봇 노트북 — [CHECKLIST.md](CHECKLIST.md) 7절 "10/5 실물")** — Panda 쪽 차를 반올림 없이 쓰면 264.07mm (시작 1.17328 − 닿는 점 0.90921)

| 집게 | `Zt` (플랜지) | Mirobot 홈이 닿는 점 위 | 배율 | 쓰는 곳 |
|---|---|---|---|---|
| **연 상태 `S30`** | **55.715mm** | 175.005mm | **0.6627 → 0.663** | **배율** |
| 닫은 상태 `S70` | 60.713mm — 끝단이 5.0mm 더 내려온다 | 170.007mm | (0.644) | **세로 하한** (7절) |

- **배율은 연 상태로 정한다** — 첫 과제는 집게를 연 채 손을 뻗고, Panda 는 연 채·닫은 채 닿는 높이가 같았다(3절). 연 상태끼리 맞추는 게 같은 상태끼리다
- 세 자리(X 200 Y 0 / X 240 Y ±60)의 1mm 차는 종이 시험의 잡음으로 보고 한 값으로 통일했다 — 근거는 CHECKLIST 7절. 종이 시험 분해능은 ±1mm 쯤
- 먼저 닿는 곳은 **집게 양 끝단이 동시에** — 공구 축이 수직이었다
- 측정 전에 **그리퍼 장착부가 헐거워 연 상태에서 2mm 처져** 있었다. 조인 뒤 잰 값이다
- 홈 `?` 은 `198.670, 0.000, 230.720` 으로 정확하다 — 식에 쓰는 230.72 그대로
- **예상 범위(0.63~0.70) 안이다.** Mirobot 100mm 가 Panda 151mm

## 5. 가로 — 장면이 맞춘다

블록을 실물 작업대에서 Mirobot 이 닿는 곳에 놓고, 시뮬 장면은 그 자리를 거꾸로 옮겨 만든다 ([CHECKLIST.md](CHECKLIST.md) 4-3 D).

```
시뮬 탁상 위치 = Panda 시작 xy + (Mirobot 위치 − 홈 xy) / s
```

s 0.663 (10/5 실측) 이면

| Mirobot 플랜지 | 시뮬 탁상 (x, y) m |
|---|---|
| X 150, Y 0 | (−0.282, 0.000) |
| X 260, Y 0 | (−0.116, 0.000) |
| X 200, Y +100 | (−0.206, +0.151) |
| X 200, Y −100 | (−0.206, −0.151) |

**블록 자리는 작업대 높이에서 닿아야 한다** — `Zt` 를 잰 세 자리(X 200 Y 0, X 240 Y ±60)는 작업대 높이에서 **닿았다** (10/5).
**안쪽은 아직 모른다** — 어깨(J2) 내측 한계가 플랜지 X 128~139mm 인 건 **Z 165~231 에서만** 쟀다(10/5). 블록 자리의 안쪽 끝 X 150 이
**작업대 높이(플랜지 Z 70 근처)** 에서도 닿는지는 확인해야 한다 (6절)

## 6. 로봇 노트북에서 잴 것

- [x] **홈의 `?`** — 호밍 직후 한 줄. 식에 쓰는 홈 플랜지 Z 230.72(9/13)가 그대로인지
  → **그대로다 (10/5)** — `Angle 0 ×7, Cartesian 198.670, 0.000, 230.720`. `G0` 로 같은 좌표를 보내면 230.449 — 0.27mm 는 IK 로 풀 때만 생긴다
- [ ] **`Zt`** — 공구 축 수직(`A0 B0 C0`), 집게를 연 채, 세 자리 (X 200 Y 0 / X 240 Y +60 / X 240 Y −60).
  각 자리 위 안전한 높이에서 Z 를 5mm 씩, 가까워지면 1mm 씩 내린다. **집게 끝과 작업대 사이에 종이 한 장**을 끼워 두고
  종이가 안 빠지는 첫 높이에서 `?` 를 읽는다. **Mirobot 은 힘을 못 느껴 작업대를 누르면 스텝을 잃는다** — 닿기 전에 멈춘다.
  집게에서 가장 먼저 닿는 부분도 적는다. ±1mm
  → **쟀다 (10/5) — 연 상태 55.715mm**, 세 자리 공통으로 통일. 집게 양 끝단이 동시에 닿는다. 4절 실측 표
- [x] (있으면) 같은 첫 자리에서 집게를 닫은 채 한 번 더 — Mirobot 집게는 닫을 때 손가락 끝 높이가 바뀌는지
  → **바뀐다 (10/5) — 닫은 상태 60.713mm, 끝단이 5.0mm 더 내려온다.** 조가 평행 이동이 아니라 회전식이다. Panda 와 다르다
- [ ] **작업대 높이에서 안쪽 한계** (10/5 새로) — 블록 자리의 안쪽 끝 X 150~170 에서, 작업대 바로 위(플랜지 Z 70~80)까지 내려가는지.
  J2 내측 한계는 Z 165~231 에서만 쟀다
  →

## 7. 의견 — 정렬 오차를 얼마나 봐도 되나

- **위아래가 비대칭이다** — 첫 과제는 손 뻗기만이라 낮으면 작업대·블록과 부딪히고, 높으면 손해가 없다.
  그래서 ±가 아니라 **"아래로 0, 위로 +10~20mm"** 로 보고, 위로 여유를 조금 얹는 쪽을 권한다
- **아래 여유가 작다** — 세로 움직임은 배율만큼 줄어서, LIBERO 정책이 그릇을 집으러 닿는 점 4mm 위까지 오던 동작이 Mirobot 에서는
  **2.5~2.8mm 위**가 된다. **`Zt` 는 ±1mm 로 재야 한다.** 다만 우리 첫 과제(손 뻗기)를 fine-tuning 하면 그만큼 내려오지 않을 수 있다
- **실측 뒤 — 세로 하한은 플랜지 Z 66~71mm 다 (10/5)** — 집게를 닫은 상태의 `Zt` 60.713mm 에 여유 5~10mm. 닫으면 끝단이 5mm 더 내려오는데
  Panda 는 연·닫은 높이가 같아서, **닫은 상태에서는 정렬이 Mirobot 쪽으로 5mm 불리하다.** 배율 0.663 으로 LIBERO 정책의 최저 동작을 옮기면
  연 상태로는 닿는 점 위 **2.65mm** 지만 닫은 상태로는 **2.35mm 아래**다. 종이 시험의 분해능도 ±1mm 라
  **문서의 기준만으로는 못 지킨다 — 번역기나 `run_gcode` 가 Z 하한 아래 줄을 막아야 한다** (10절)
- **나중에 집기로 가면** 블록 반높이 안쪽이라 ±5mm 정도
- **Z 만 다른 배율은 최후 수단** — 세 축 같은 배율을 풀면 접근 각도가 찌그러진다. 새 방식에서는 배율이 세로로 정해지고 가로는 장면이
  맞추므로 필요해질 일이 거의 없다

## 8. 버린 것 — 배율별 Mirobot 시작 자세 (10/5 오전~오후)

기록으로만 남긴다 (`Zt` = 닿는 점 플랜지 Z, 세로는 닿는 점끼리).
