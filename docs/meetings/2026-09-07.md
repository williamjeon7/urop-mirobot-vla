### 노트북에서 모델 없이 가능한 범위 (2026-09-09 확인)

세 과제 모두 **모델 다운로드 없이** 개인 노트북에서 가능하다. 모델이 필요한 시점은
학습된 정책으로 추론을 돌릴 때다.

단, `cosmos-policy` 는 `.gitignore` 라 `mirobot-vla` clone 에 따라오지 않으므로
따로 받아야 한다 (약 20MB). `../VENDORED.md` 참조.

### LIBERO 롤아웃 관측 구조

`cosmos_policy/experiments/robot/libero/sample_libero_10_observation.pkl` (384KB) 에
관측 하나가 통째로 들어 있다. LIBERO 설치 없이 `pickle` 로 바로 열린다.

| 키 | 형태 | 비고 |
|---|---|---|
| `primary_image` | (256, 256, 3) uint8 | `obs["agentview_image"]` |
| `wrist_image` | (256, 256, 3) uint8 | `obs["robot0_eye_in_hand_image"]` |
| `proprio` | (9,) float64 | 아래 참조 |

`libero_*_metainfo.json` 4개 (5.2MB) 에는 태스크별 demo 목록이 있고, 각 demo 마다
`success` 라벨과 `initial_state` 가 붙어 있다. **실패한 demo 도 라벨링되어 있다.**

롤아웃 영상 저장은 `libero_utils.py` 의 `save_rollout_video()` 와
`save_rollout_video_with_future_image_predictions()`, 프레임 누적은
`run_libero_eval.py` 의 `replay_images` 리스트.

### FK / IK — 조사한 사실

LIBERO 의 액션은 **7차원**이다.

```python
# libero_utils.py:42
def get_libero_dummy_action(model_family):
    return [0, 0, 0, 0, 0, 0, -1]
```

delta EEF pos(3) + delta rot(3) + gripper(1). 관절 제어였다면 Panda 7축 + 그리퍼로
8차원이 나온다. 즉 **Cartesian 델타를 내보내고 IK 는 robosuite 컨트롤러가 내부에서
푼다** (OSC 계열).

**그리고 LIBERO 의 proprio 9차원이 우리 `common/schema.py` 의 STATE 와 정확히 같다.**

```python
# LIBERO  run_libero_eval.py:334
np.concatenate((obs["robot0_gripper_qpos"],  # 2
                obs["robot0_eef_pos"],       # 3
                obs["robot0_eef_quat"]))     # 4  = 9

# 우리    common/schema.py
[gripper_left_qpos, gripper_right_qpos,           # 2
 eef_pos_x, eef_pos_y, eef_pos_z,                 # 3
 eef_quat_w, eef_quat_x, eef_quat_y, eef_quat_z]  # 4  = 9
```

액션도 양쪽 다 7차원으로 동일하다. 우리 Mirobot 데이터가 LIBERO 규약을 그대로
이식한 것이라는 뜻이다.

우리 쪽도 이미 같은 계열이다 — `common/gcode.py` 의 `state_to_gcode()` 가 EEF 좌표를
`G0 X.. Y.. Z..` 로 보내고 Mirobot 펌웨어가 IK 를 푼다. 관절공간으로 갈지 여부가
비교의 쟁점이 된다.

### 시뮬 실행까지 하려면

`libero_requirements.txt`: robosuite 1.4.1, mujoco 3.3.2, bddl, easydict,
cloudpickle, gym, draccus, imageio[ffmpeg]. 모델은 여전히 불필요하다.
리눅스 기준 스택이라 윈도우에서는 마찰이 있을 수 있고, 서버 `cosmos-policy/.venv`
에는 이미 mujoco 가 들어 있다.
