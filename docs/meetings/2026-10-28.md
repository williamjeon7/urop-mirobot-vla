## 다음 미팅까지 — action plan (11/2)

### 1. Mirobot 실제 환경 측정 및 LIBERO Tabletop 환경 수정

담당: 민수

- 실제 환경 측정: 테이블·오브젝트의 크기와 위치, Mirobot 설치 위치, RealSense D405 카메라의 위치·각도 측정
- LIBERO 환경 수정: 측정값을 바탕으로 XML/MJCF, 로봇 모델 및 LIBERO Tabletop 환경 코드를 수정하여 실제 환경과 시뮬레이션 환경을 최대한 일치시킴
- RGB 색상 보정: ColorChecker를 활용하여 D405와 LIBERO Tabletop의 RGB 색상 차이를 측정하고, Color Mapping 결과를 바탕으로 LIBERO 코드의 조명·재질·색상 설정을 수정하여 RGB 오차 최소화
- 환경 일치 검증: 실제 D405 촬영 이미지와 LIBERO 렌더링 이미지를 비교하여 오브젝트 배치, 카메라 시점 및 RGB 색상 차이 확인

목적: 실제 Mirobot 환경과 LIBERO 시뮬레이션 환경 간의 시각적·기하학적 차이를 최소화하여 Sim-to-Real Domain Gap을 줄임.

### 2. Mirobot 실행 및 RGB 영상·동작 데이터 수집

- 데이터 누락 및 시간 동기화 오차 검증

Image(t) + Proprio(t) + Action(t)

담당: 석환

- Proprioception 및 Action을 float32 배열로 구성
- Cosmos Policy의 Dataset Loader에서 사용할 수 있도록 LIBERO 호환 HDF5 데이터셋 생성
- 데이터 구조 및 학습 데이터 로딩 정상 동작 검증

### 5. Cosmos Policy-Predict2-2B 파인튜닝

담당: 민수, 석환 (공동)

- 기존 Cosmos Policy LIBERO 체크포인트를 초기 가중치로 활용
- Train Dataset (총 100 Episodes 가정)
  - Panda (Simulation): 90 Episodes (90%)
  - Mirobot (Real-world): 10 Episodes (10%)
- Panda와 Mirobot의 Action Space 및 Proprioception 형식을 모델 입력에 맞게 통일
- 혼합 데이터셋을 활용하여 Cosmos Policy-Predict2-2B 파인튜닝
- 별도의 Validation/Test 데이터셋을 구성하여 Panda 및 Mirobot 환경에서 성능 평가

목적: 기존 Panda 기반 정책을 실제 Mirobot 환경에 적응시키고, 시뮬레이션 데이터와 실제 로봇 데이터를 혼합한 학습의 효과를 검증함.
