# 그리퍼 이동 시간 측정

2026-10-29, `docs/W9/gripper_openclose.mp4`를 분석했습니다. 첫 번째 개폐는 닫기·열기 한 쌍으로 해석하여 처음 두 이동 구간을 제외했습니다.

## 적용 설정

```text
--initial-s 40 --open-s 40 --closed-s 60 --gripper-seconds 1.0
```

열기 S40·닫기 S60은 `robot/inverse_kinematics.py`의 실제 전송 명령값입니다. 영상 자체에는 명령 로그가 없어 S값을 독립적으로 검증할 수는 없습니다. 녹화 전 `←`로 집게를 열어 두어야 `initial-s 40`과 일치합니다. 옵션을 지정하는 것만으로 집게가 열리지는 않습니다. COM 포트는 영상으로 확인할 수 없으므로 기존 포트를 유지하고 장치 관리자에서 확인합니다.

## 측정 방법과 한계

OpenCV로 모든 프레임을 읽고, 원본 좌표 x=300:680, y=760:1180 영역을 절반 크기로 줄여 Farneback optical flow를 계산했습니다. 상단 30행의 중앙 이동 벡터를 빼 카메라 흔들림을 보정한 뒤, 집게 영역(x=20:160, y=55:190) 이동량의 85백분위수를 사용했습니다. 0.65픽셀/프레임을 넘는 구간을 찾고, 최대 3프레임 간격을 연결한 다음 0.4픽셀/프레임까지 양쪽 경계를 확장했습니다. 시간은 끝 타임스탬프에서 시작 타임스탬프를 빼고 프레임 간격 약 1/30초를 더한 추정입니다. 시작 닫힘·열림 구간의 확대 연속 프레임도 눈으로 확인했습니다.

카메라 흔들림과 경계 검출 때문에 몇 프레임의 오차가 있습니다. 위 시간은 MP4 재생 타임스탬프 기준이며, 원본이 슬로모션이나 배속으로 내보내진 경우 실제 시간에 맞춰 재측정해야 합니다. 명령 시각과 동기화된 촬영이 아니므로 명령 수신 지연은 측정하지 못했습니다. 물체 없이 개폐한 영상의 이동 시간을 사용하며, 물체를 잡았을 때의 실제 폭이나 힘은 보정하지 않습니다. 후처리의 집게 상태는 이 시간에 따른 선형 추정값입니다.
