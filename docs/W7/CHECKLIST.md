# W7 — D405 영상 촬영 진행

> **기록** · 확인 2026-10-12 · 기준 Windows 노트북, RealSense D405
> D405 컬러 영상 확인과 첫 MP4 촬영의 작업 상태·설정·결과를 기록한다.

## 이번 작업

D405를 노트북에 연결한 상태에서 컬러 영상을 먼저 확인하고, 짧은 MP4 시험 영상을 저장한다. 설치·녹화 절차는 [SETUP_D405_WINDOWS.md](SETUP_D405_WINDOWS.md)에 정리한다.

## 작업 상태

| 작업 | 상태 | 확인 내용 |
|---|---|---|
| D405 노트북 연결 | 확인 완료 | Windows 장치 목록에서 D405 확인, 장치 상태 OK |
| Viewer 설치·실행 안내 정리 | 완료 | W7 폴더의 절차 문서 작성 |
| Viewer 다운로드·실행 | 완료 | 공식 RealSense Viewer v2.59.1.11053 다운로드 및 실행 |
| Viewer에서 D405 인식 | 확인 완료 | 왼쪽 장치 목록에 RealSense D405, USB 3.2 표시 |
| 컬러 영상 스트리밍 | 확인 완료 | 2D 화면에서 Color RGB8, 848×480, 30 FPS 설정으로 실제 영상 및 장면 변화 확인 |
| 첫 MP4 촬영·재생 | 미확인 | 약 10초 화면 녹화 후 저장 파일 재생 확인 필요 |

## 다음 진행

1. 실행 중인 Viewer에서 카메라 위치와 촬영 대상을 맞춘다.
2. 약 10초를 녹화하고 저장된 MP4를 재생한다.
3. 아래 촬영 기록에 녹화 설정과 결과를 채운다.

## 촬영 기록

## 진행 기록

- **2026-10-12**: D405 노트북 연결을 사용자 메시지로 확인. 컬러 영상만 먼저 촬영하기로 함. Viewer 설치·화면 녹화 안내를 작성하고 W7 폴더에서 진행 내용을 관리하기로 함.
- **2026-10-12 실제 실행**: `C:\Users\<USER>\Downloads\RealSense.Viewer-v2.59.1.exe`를 실행해 D405 인식과 컬러 스트리밍을 확인했다. Depth를 해제하고 Color를 선택한 뒤 2D 화면에서 Stereo Module을 켰다. 여러 시점의 화면에서 장면이 바뀌는 것을 확인했으며, Viewer는 스트리밍 중인 상태로 유지했다. 펌웨어는 변경하지 않았다. MP4 녹화·재생은 아직 실행하지 않았다.
